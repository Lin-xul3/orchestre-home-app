# 乐团家投资人演示 App

这是一个无需后端即可运行的高保真交互原型，用于展示乐团家的核心产品闭环：排练管理、AI 总谱拆分、实时批注协作和成员管理。

## 运行

直接双击 `index.html`，或在本目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 建议演示路径

1. 在“排练总览”点击“导入总谱”。
2. 选择“使用示例总谱演示”，观察 AI 处理流程。
3. 进入“智能乐谱”，切换声部图层并点击谱面添加批注。
4. 进入“协同排练”，展示在线成员、声部分组和录音分析。
5. 进入“成员管理”，搜索成员并说明出勤与练习闭环。

界面中的处理进度、在线人数、识别置信度和排练数据均为演示数据。
